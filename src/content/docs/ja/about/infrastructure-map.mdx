## マップの位置づけ

Marron のインフラマップは単なる作図ツールではありません。Resource と Relation を視覚化し、マップ上の操作を実際の管理計画につなぐ UI です。

物理図と論理図を別々の管理データとして重複させず、同じ Resource モデルを異なるビューで表示します。

## ビュー

- **トポロジー:** 機器、インターフェース、物理・論理接続
- **ラック:** ラック正面・背面、U位置、搭載機器
- **フロア / 部屋:** ラックや機器の設置場所、部屋間の関係
- **論理ネットワーク:** VLAN、サブネット、IP、ルーティングなど
- **リソース / サービス:** VM、ストレージ、アプリケーション、依存関係

ラック図は重要なビューとして扱い、物理配線ではサーバー NIC からスイッチポートまで、ポート番号やケーブル情報を追えることを目指します。パッチパネルなども段階的に対応します。

## レイアウト

座標や表示属性はビューごとに独立して保存します。自動レイアウトと手動配置を併用し、利用者が固定した位置は自動レイアウトで不用意に変更しません。同じ Resource を複数のマップで再利用できます。

## Desired / Observed の重ね合わせ

設計上の接続と観測された接続を重ねて表示し、差分を明示します。例えば、設計上は接続されているリンクが実際には Down である場合、マップ上で区別できるようにします。

## マップからの変更

ドラッグ＆ドロップなどの操作から、グループ作成、VM 配置、IP 割り当て、物理ケーブル接続、VLAN 設定、管理ポリシー変更などの計画を作成できるようにします。

ただし、マップ操作がそのまま機器へ即時反映されることはありません。変更は Plan / Preview で影響と差分を確認し、ポリシーと承認に従って Apply します。

例えば VLAN 作成では、VLAN ID とサブネットの競合、IPAM、機器の対応能力、ポートの Access / Trunk 設定、依存関係、通信影響を検証します。
